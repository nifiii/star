# UI/UX 设计系统

## 1. 背景

产品是家长和教练重复使用的运动数据查询工具，核心任务是快速扫描比分和成绩。

## 2. 目标

- 查询控件可快速理解，结果优先于装饰。
- 颜色不能单独承担胜负含义。
- 移动端和桌面端都能阅读完整比分。

## 3. 方案

- 视觉方向：深绿强调色 `#166b54`、灰白底色 `#f6f8f7`、轻边框，减少装饰与阴影；不引入新视觉框架。
- 布局：最大 1200px 内容区，顶部双入口、横向查询、通栏结果；900px 以下切换卡片，600px 以下表单单/双列自适应。
- 字体：沿用系统无衬线字体；比分使用等宽数字。
- 间距：8px 主节奏，面板内边距 PC 24~28px、手机 18px，12~16px 圆角；移除固定 400px 高度与嵌套滚动。
- 组件：姓名输入、性别按钮、城市/赛事筛选、查询按钮、统计卡片、比赛表格、空/错状态卡片。
- 交互：查询期间禁用重复提交；错误状态保留用户输入；键盘 Enter 可提交；焦点必须可见。
- 可访问性：文本与背景达到 WCAG AA 对比度；胜负同时显示文字/图标；触控目标不小于 44px。
- 数据展示：比分原文按 A/B 顺序保留；可解析时另显示胜/负，平分/0:0/异常/身份不明时显示“待确认”。赛事和组合完整换行。
- 视觉验收：至少验证 1280px、768px、375px 三个宽度和加载/空/错误/部分成功状态。

## 4. 风险

- 已按用户要求替换儿童化配色和浮动装饰；手机不隐藏关键赛事与组合字段。
- 视觉检查标准和验收证据见 `responsive-redesign.md`、`responsive-validation.md`。
