# 验收测试

## 1. 背景

验收必须覆盖用户查询主路径、异常路径和数据质量边界。

## 2. 目标

让实现人员不依赖猜测即可验证 MVP。

## 3. 方案

2026-10-22 增补（此次响应式改造）：360/390/768/1440px 无全页横向溢出；<900px 显示卡片；完整多局比分和双打组合换行；分页每页 20 条且回到结果区域；导出全部查询记录；切换导航保留原结果；输入为空就地提示且不请求 API；HTTP 500/403 与合法空数组区分；清除缓存同步作用于浏览器和会话；不依赖 auth_config.json 才能查询已有数据。当前版本不以早期规划中的服务端时间过滤和结构化状态作为已实现项。

### 示例数据

```json
{
  "playerName": "示例运动员",
  "playerA": "示例运动员",
  "playerB": "对手甲",
  "score": "21:15, 18:21, 21:19",
  "game_name": "2026 广州青少年公开赛",
  "groupName": "U12 男单",
  "matchTime": "2026-10-20",
  "round": "决赛"
}
```

- `AC-001` Given 姓名为空，When 点击查询，Then 不发起 API 请求并显示校验提示。
- `AC-002` Given API 返回一条记录，When 查询成功，Then 展示赛事、组别、对手、原始比分和更新时间。
- `AC-003` Given API 返回多局比分，When 展示结果，Then 保留完整比分，并仅在多局完整可解析时计算胜负。
- `AC-004` Given API 返回 0 条，When 查询结束，Then 显示空数据状态且不显示“查询成功找到 0 场”以外的误导统计。
- `AC-005` Given API 返回 401/403，When 查询结束，Then 显示凭证/权限错误，不显示为空数据。
- `AC-006` Given 网络超时，When 查询结束，Then 显示可重试错误并保留输入条件。
- `AC-007` Given 部分记录缺失比分，When 查询成功，Then 显示记录并标记“结果待确认”，页面不崩溃。
- `AC-008` Given 同名运动员存在，When 查询结果返回，Then 显示筛选条件和同名提示，不自动断言身份。
- `AC-009` Given 选择性别、城市和赛事关键字，When 查询，Then 请求参数和缓存键包含全部筛选条件。
- `AC-010` Given 凭证未配置，When 启动采集服务，Then 服务明确失败并不使用源码默认密码。
- `AC-011` Given 双打记录的组合文本包含目标个人姓名，When 查询，Then 该记录命中且展示完整组合文本。
- `AC-012` Given 赛事不在广东省或早于最近一年，When 查询，Then 该记录不返回。
- `AC-013` Given 比赛为退赛、弃权、未完赛或比分缺失，When 展示结果，Then 保留原始记录并显示“待确认”。

## 4. 风险

- `AC-003` 的“胜负”判定规则依赖 `BR-003`，在规则未确认前只能验收原始比分展示。
- 真实华体汇返回字段需要脱敏样本或本地 fixture，不能在测试中提交账号、token 或原始敏感响应。
